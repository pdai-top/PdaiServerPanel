# Third-Party Notices

This repository depends on external Go and npm packages whose licenses are
separate from this repository's MIT license.

This file is not a replacement for upstream attribution. Upstream attribution
for web-casa/webcasa is kept in `LICENSE` and `NOTICE`.

Before publishing a release, regenerate a dependency license inventory for the
exact build you are shipping and include it with the release artifacts.

Current source of truth for frontend dependency licensing is:

- `web/package-lock.json`

If you ship bundled assets, also include any notices required by included
fonts, icons, images, or other imported assets.
